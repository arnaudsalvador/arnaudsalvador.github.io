### Productivity & Workflow

- [ArtCraft](https://getartcraft.com/apps) - Adobe suite apps, open-sourced
- [Notion](https://www.notion.so/desktop) - All-in-one workspace for notes, projects, and organization
- [Rectangle](https://rectangleapp.com) - Window management with keyboard shortcuts
- [Tangerine](https://tangerineformac.com) - Offline, zero-click file conversion
- [Vorssaint](https://github.com/vorssaint/vorssaint-utils) - All-in-one macOS toolkit for system monitoring, window management, clipboard history, audio controls, and file utilities
- [BoringNotch](https://github.com/TheBoredTeam/boring.notch) - Turn MacBook's notch into a Dynamic Island-style hub
- [IceMelt](https://github.com/pnikolaidis/icemelt) - macOS menu bar manager
- [Dropover](https://dropoverapp.com) - Drag-and-drop shelf for files and sharing
- [FileVert](https://filevert.fr/en) - File transfer
- [Fichiers](https://lasuite.numerique.gouv.fr/produits/fichiers) - File storage and sharing
- [BetterDisplay](https://github.com/waydabber/BetterDisplay) - Advanced display management for macOS

### Writing & Reference Management

- [Overleaf](https://www.overleaf.com) - Online LaTeX editor
- [Texmaker](https://www.xm1math.net/texmaker/download.html) - Free cross-platform LaTeX editor (requires a LaTeX distribution, such as [MacTeX](https://www.tug.org/mactex/mactex-download.html) for macOS)
- [Detexify](https://detexify.kirelabs.org/classify.html) - LaTeX handwritten symbol recognition
- [Mendeley](https://www.mendeley.com/download-reference-manager/macOS) - Reference manager with online synchronization

### Development & Terminal Tools

- [VS Code](https://code.visualstudio.com) - Source-code editor
- [iTerm2](https://iterm2.com) - Terminal emulator
- [TermHere](https://hashbang.productions/apps/termhere/) - Terminal shortcut for current directory (direct download [here](http://arnaudsalvador.github.io/files/TermHere.zip))
- [Meld](https://meldmerge.org) - Visual diff and merge too (macOS app direct download [here](https://github.com/yousseb/meld/releases/download/osx-19/meldmerge.dmg))
- [GitHub Desktop](https://desktop.github.com) - GUI for Git
- [Mist](https://github.com/ninxsoft/Mist) - Lists and downloads macOS Firmwares and Installers
- [OpenCore Legacy Patcher](https://dortania.github.io/OpenCore-Legacy-Patcher/) - macOS installation on unsupported Macs
- [uv](https://docs.astral.sh/uv/) - Fast Python package and project manager
